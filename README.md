# 📌 GRUD Angular

## 📖 Sobre o projeto

Este repositório foi criado com o objetivo de **estudo e prática do framework Angular**, focando principalmente nos conceitos de **CRUD (Create, Read, Update, Delete)**, organização de componentes, uso de **services**, rotas e boas práticas de versionamento com Git.

O repositório funciona como um **monorepo**, contendo diferentes projetos Angular em **versões distintas do framework**, permitindo comparar mudanças entre versões e reforçar o aprendizado.

---

## 📂 Estrutura do Repositório

GRUD-Angular/
├── project-angular17/ # Projeto desenvolvido com Angular 17
├── project-angular21/ # Projeto desenvolvido com Angular 21
├── README.md # Documentação do repositório


Cada pasta representa um **projeto Angular independente**, com sua própria configuração, dependências e estrutura.

## ⚙️ Funcionalidades

Os projetos deste repositório abordam:

- ✅ Criação de componentes Angular  
- ✅ Uso de **Services** para lógica de negócio  
- ✅ Separação de responsabilidades entre componentes e serviços  
- ✅ Estrutura de rotas  

> As funcionalidades podem variar de acordo com a versão do Angular utilizada em cada projeto.
